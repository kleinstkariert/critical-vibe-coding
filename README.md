# Critical Vibe Coding

Critical Vibe Coding is a seminar about living and working with AI in media-art practice. It is part of Interface Cultures at Kunstuniversität Linz. The course combines screen-free group discussion, critical research, technical experiments, and individual project work. The technical materials support different practices. They do not define one correct setup.

- This is a seminar, not a software-certification course.
- A large part of the work is group discussion without screens.
- Technical setups are personal and may differ.
- You may use AI, use it critically, or work through research and refusal.
- No purchase is required. Alternatives are allowed.
- This repository holds shared questions, session materials, technical notes, and references.
