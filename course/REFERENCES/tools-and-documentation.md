# Tools and documentation

This page is a pointer. It does not compare tools.

**One canonical comparison:** [Vibe-coding tools and agent environments, late 2026](../../research/software&DataManagement/vibe-coding-tools-and-agent-environments.md). It defines the words (assistant agent, coding agent, agent harness, environment, editor, orchestrator, protocol) and gives dated facts on licences, model access and prices. It covers editors, terminal agents, cloud agents and the tools the Stack Overflow survey ranks high: Claude Code, GitHub Copilot, Codex, Kiro, JetBrains, Gemini, Devin and Warp, plus Zed and AgentCraft. Checked 2026-11-24. Open that page first.

Why the course default is an assistant plus a coding agent: [Hermes vs coding agents](../PRACTICE/01-harness-and-agents/hermes-vs-coding-agents.md). What a harness is: [What is a harness](../PRACTICE/01-harness-and-agents/what-is-harness.md).
