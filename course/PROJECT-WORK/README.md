# Project work

This folder collects the documents for your own practice.
The documents are templates. They do not require one agent architecture.
A student who works with Hermes, Cursor, a local script, a visual tool, or no AI can use the same framework.

| Document | Content |
|---|---|
| [Minimum path](minimum-path.md) | The required work. |
| [Project path](project-path.md) | Proposal, midpoint and final in one page. |
| [Provenance and process log](provenance.md) | The record of task, model, tools, decisions and outcome, with the running log. |
| [Verification](verification.md) | How you check the result. |
| [Reflection](reflection.md) | The critical reflection, with prompts and reading. |
| [Interface score](interface-score.md) | Scaffold for Session 06 and later. Optional. |
