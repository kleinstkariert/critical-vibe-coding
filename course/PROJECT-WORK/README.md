# Project work

This folder collects the documents for your own practice.
The documents are templates. They do not require one agent architecture.
A student who works with Hermes, Cursor, a local script, a visual tool, or no AI can use the same framework.

| Document | Content |
|---|---|
| [Minimum path](01_minimum-path.md) | The required work. |
| [Project path](02_project-path.md) | Proposal, midpoint and final in one page. |
| [Provenance and process log](03_provenance.md) | The record of task, model, tools, decisions and outcome, with the running log. |
| [Verification](04_verification.md) | How you check the result. |
| [Reflection](06_reflection.md) | The critical reflection, with prompts and reading. |
| [Interface score](05_interface-score.md) | Scaffold for Session 06 and later. Optional. |
