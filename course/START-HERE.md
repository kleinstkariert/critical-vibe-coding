# START HERE

Welcome to **Critical Vibe Coding** (Interface Cultures).  
This page is the on-ramp. Everything else hangs off the [course outline](course-outline.md) and [session notes](sessions/).

---

## What this course is

You build and run a **personal LLM-agent setup** while unpacking political-economic, authorship, labour, and ecological questions. The **agent setup itself** (harness, wiki, tools) is treated as artistic/technical material — not only the generated output.

Default stack: **Hermes Agent** + **Obsidian** (LLM Wiki habits) + model(s) you can access. Twin tracks every week: technical + critical check-in.

---

## Install order (before / during weeks 2–4)

1. Knowledge store with **phone sync** — default Obsidian; **alternatives allowed** → [knowledge-store-options.md](knowledge-store-options.md) · [howto-obsidian-setup-and-sync.md](howto-obsidian-setup-and-sync.md)  
2. Note which **LLM access** you already have. Campus academic AI often has **no API for agents** → [academic-ai-austria.md](academic-ai-austria.md)  
3. **Hermes Agent** (cloud model OK first) → [howto-hermes-setup.md](howto-hermes-setup.md)  
4. Skim **harness** → [what-is-harness.md](what-is-harness.md) (session 2)  
5. Prompting / model choice → [prompting-and-model-choice.md](prompting-and-model-choice.md)  
6. Optional **local** models / hardware → [howto-local-llm-hardware.md](howto-local-llm-hardware.md) (session 4)

Keep API keys out of synced notes.

**Every class:** 10:00–12:00; listen-only check-in (morning + AI since last met). From week 2: one student pair (~15 min) on a **humanities** question — see [course-rhythm.md](course-rhythm.md).

## How to use this repo with Obsidian

*technical suggestion:* Clone or download this repo into a folder next to (or inside) your personal vault, e.g. `Obsidian/CVC-course/`. Your **LLM Wiki** (`wiki/` or agent-writable folders) stays in *your* vault; this repo is the **syllabus**, not your diary.

GitHub renders Markdown in the browser — you do not need Obsidian to *read* the course pack.
