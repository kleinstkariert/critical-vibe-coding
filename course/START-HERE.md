# START HERE

Welcome to **Critical Vibe Coding** (Interface Cultures).  
This page is the on-ramp. The generated list of current pages is the [course map](course-map.md). Everything else hangs off the [course outline](syllabus/course-outline.md) and [session notes](sessions/).

## What you must do

A personal manifesto on how you want to use AI in your practice is required.
It names no product.
Session 01 introduces it. You develop it through the meetings. You hand it in at the end.
It is not week-1 homework.
The technical object is a student-designed agentic production system.
Read the [minimum path](minimum-path.md) before the install list.
The manifesto, the minimum path, and the group input presentations are required.
No purchase is required. Alternatives are allowed.
Hermes is one *reference implementation*. Sebastian will install it with the class.
That install is a *demonstration*. It is *not required for assessment*.
Claude Code, Cursor, OpenCode, a local script, or another agent are valid systems.

## What this course is

You build and run a **personal LLM-agent setup** while unpacking political-economic, authorship, labour, and ecological questions. The **agent setup itself** (harness, wiki, tools) is treated as artistic/technical material — not only the generated output.

Default stack: **Hermes Agent** + **Obsidian** (LLM Wiki habits) + model(s) you can access. Twin tracks every week: technical + critical check-in.

*reference implementation.* The sentence above names one example. The assessed object is your own system. See the [minimum path](minimum-path.md). A structured wiki does not make the notes true: [what structure improves](setup/llm-wiki-standard-files.md#what-structure-improves).

## How to use this repo with Obsidian

*technical suggestion:* Clone or download this repo into a folder next to (or inside) your personal vault, e.g. `Obsidian/CVC-course/`. Your **LLM Wiki** (`wiki/` or agent-writable folders) stays in *your* vault; this repo is the **syllabus**, not your diary.

GitHub renders Markdown in the browser — you do not need Obsidian to *read* the course pack.
