## What this course is

You build and run a **personal LLM-agent setup** while unpacking political-economic, authorship, labour, and ecological questions. The **agent setup itself** (harness, wiki, tools) is treated as artistic/technical material — not only the generated output.

Default stack: **Hermes Agent** + **Obsidian** (LLM Wiki habits) + model(s) you can access. Twin tracks every week: technical + critical check-in.

---

## Install order (before / during weeks 1 to 3)

The course has **eight sessions**: [course-outline.md](syllabus/course-outline.md).

1. Knowledge store with **phone sync**: default Obsidian; **alternatives allowed** → [knowledge-store-options.md](setup/knowledge-store-options.md) · [howto-obsidian-setup-and-sync.md](setup/howto-obsidian-setup-and-sync.md)  
2. Note which **LLM access** you already have. Campus academic AI has **no API for agents** → [academic-ai-austria.md](setup/academic-ai-austria.md)  
3. **Hermes Agent**, installed together in session 2. A free open model to start: Nemotron 3 Ultra through OpenRouter's free tier → [howto-hermes-setup.md](setup/howto-hermes-setup.md) §3  
4. Skim **harness** → [what-is-harness.md](concepts/what-is-harness.md) (session 2)  
5. Prompting / model choice → [prompting-and-model-choice.md](concepts/prompting-and-model-choice.md)  (session 3)
6. Optional **local** models / hardware → [howto-local-llm-hardware.md](setup/howto-local-llm-hardware.md) (session 3)

Keep API keys out of synced notes.

**Every class:** 10:00 to 12:00; listen-only check-in (morning + AI since last met). In sessions 2, 3, 5, 6 and 7: one student group (~15 min) on a **humanities** question (topics chosen in session 1); see [course-rhythm.md](syllabus/course-rhythm.md).

## How to use this repo with Obsidian

*technical suggestion:* Clone or download this repo into a folder next to (or inside) your personal vault, e.g. `Obsidian/CVC-course/`. Your **LLM Wiki** (`wiki/` or agent-writable folders) stays in *your* vault; this repo is the **syllabus**, not your diary.

GitHub renders Markdown in the browser — you do not need Obsidian to *read* the course pack.
