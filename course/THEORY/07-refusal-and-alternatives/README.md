# Refusal and alternatives

This folder is an index. It has no note of its own. Refusal is taught inside other notes. This page says where, so you can read the parts together.

What belongs here: refusal as a position (not using AI, or not using one feature), alternatives to the default tool, and the cost of both. A longer note can be added when the course has one. Until then, use the links below.

Doubt and refusal are valid positions. See [seminar](../../SEMINAR.md).
