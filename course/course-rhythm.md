# Course rhythm

*requirement* from brief + 2026-10-27 teaching decisions. Parent: [[timeline]] · [[course-outline]].

**Slot:** **120 minutes**, **10:00–12:00**, with a **5–10 minute break**. Session files list **clock times** (not only durations).

Teacher-only prep (not in this public repo): Obsidian vault `Teaching/CriticalVibeCoding/`.

---

## 1. Check-in (every session)

**Listen only.** No fixing during the round.

| Prompt | |
|---|---|
| 1 | How was your morning? |
| 2 | What did you do with AI since we last met, and how was that experience? |

- **30–60 seconds per person** → ~20 students ≈ **10:00–10:20**
- Visible timer; teacher models brevity  
- Themes on the board *after* the round if needed  

---

## 2. Theory vs practice (*requirement* — owner definition)

| | **Student input (~15 min)** | **Teacher block after that** |
|---|---|---|
| Call it | **Theory** | **Practice** (mostly) |
| Means | Humanities / social / political-economy questions (economics included): ecology, datacenter **communities**, bias, flattening toward popular ideas, authorship, labour, regulation hype, visions/fears | Technical teaching: harness, models/install, hardware how-to, wiki, MCP, stacks… |

**Not theory:** “What is a harness?”, “How do I install Ollama?”, model shopping — those are **practice** (teacher).

Weekly **session map** can stay for now; it may shift after first student inputs. Student **topics** follow the humanities column below.

## 3. Student inputs (sessions 2–11)

- **20 students → 10 pairs**  
- One pair per class, after check-in  
- ~**15 minutes** (target **10:20–10:35**)  
- Use course research + [[references]]; not only YouTube  

### Pair ↔ session (humanities questions → then your practical teach)

| Pair | Session | Student input (theory / humanities) | Teacher practice after (technical) |
|---|---|---|---|
| G1 | 02 | Skill loss, authorship, or “who is the user sold as?” when tools get agentic — seed from [[visions-fears-regulation]] + outdoor themes | Harness = Model + …; wiki architecture |
| G2 | 03 | **Bias** / whose training corpus? **Flattening** toward popular style/voice? Closed vs open weights as power | Prompting; chat vs reasoning; Hermes install |
| G3 | 04 | Datacenters as **neighbours** (grid, water, land); who can afford “local” privacy? | Hardware paths; open models vs RAM; Ollama/Hermes Local |
| G4 | 05 | Personal knowledge bases: memory, surveillance, what should stay human-authored? | Vault practice; phone sync; Discord bridge |
| G5 | 06 | Platform dependency when many tools chain; agency vs convenience | MCP + one kitchen (incl. CAD/3D) |
| G6 | 07 | Taste flattening; agent/setup as artwork — critical art references | Agent-as-interface studio framing |
| G7 | 08 | Creative **labour** / freelance pressure / junior roles — [[../research/ai-jobs-rising-tide-productivity]] | Agents across code / node / CAD / fab |
| G8 | 09 | Midpoint: **skip** long input **or** 5–8 min one critical question from their own setup | Demos + proposals |
| G9 | 10 | Ghost work, authorship, platform ToS — session readings | Discussion facilitation + EU/AT pointer |
| G10 | 11 | Ecology / siting / when *not* — [[../research/data-centers-energy-ecology-economy]] | Comparisons + kill-switch in schema |

Suggested question stems (pairs pick one and go deep):

- Who lives next to the campus that serves *your* prompts?  
- What counts as “your” style if the default voice is the popular mean?  
- When is refusal a better artistic move than a better model?  
- Whose labour made the eval set / the cheap annotation?

## 4. Default clock (sessions 2–11)

| Clock | Block |
|---|---|
| **10:00–10:20** | Check-in (listen only) |
| **10:20–10:35** | Student pair — humanities input |
| **10:35–10:55** | Teacher bridge + start of practice (or short critical frame if needed) |
| **10:55–11:05** | **Break** (5–10 min; use full 10 if energy is low) |
| **11:05–12:00** | **Technical practice** (≥45 min; usually ~55) |

Buffer is intentional — do not pack the break. Cut teacher framing before cutting check-in or the tech floor.

### Session 1 (exception)

No student pair; no ≥45 min install lab. Rough clock in [[sessions/01-welcome-and-landscape]]: check-in/opener → lecture with Q&A after each point → homework. Break when the room needs it (~10:50).

### Sessions 12–13

No rotating humanities pair. Check-in still runs. Rest = studio/critique or finals (still ≥45 min working/presenting after break).

## 5. Crowding
