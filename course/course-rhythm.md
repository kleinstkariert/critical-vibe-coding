# Course rhythm

*requirement* from brief + 2026-10-27 teaching decisions. Applies to every meeting unless noted. Parent: [[timeline]] · [[course-outline]].

---

## 1. Check-in (every session, including session 1)

**Listen only.** Not a discussion round.

| Prompt | |
|---|---|
| 1 | How was your morning? |
| 2 | What did you do with AI since we last met, and how was that experience? |

- **About 30–60 seconds per person**  
- ~20 students → budget **~15–20 minutes** (define time-keeper)  
- Collect shared themes -> show *after* the round if needed  

---

## 2. Student inputs (from session 2)

- **20 students → 10 groups of 2**  
- **One group per class**, sessions **2–11** (10 slots). Sessions **12–13** = studio/critique + finals (no rotating theory input).  
- **~15 minutes** at the start (after check-in): teach from the repo; slides optional; one artefact / demo if useful.  
- Order: **theory → practice** (concepts before tool tours).

### Suggested group ↔ session map

| Group | Session | Input theme (use repo)                                             | Theory → practice   |
| ----- | ------- | ------------------------------------------------------------------ | ------------------- |
| G1    | 02      | Harness = Model + … ; why structure beats shopping                 | Theory              |
| G2    | 03      | Model landscape; chat vs reasoning; thinking-off                   | Theory              |
| G3    | 04      | Local hardware paths OR open models vs RAM                         | Theory → light demo |
| G4    | 05      | LLM Wiki / `SCHEMA` / lint idea                                    | Theory → vault walk |
| G5    | 06      | What is MCP? one kitchen example                                   | Theory → demo       |
| G6    | 07      | Agent as interface — one art/reference example                     | Theory              |
| G7    | 08      | One creative stack (code / node / CAD / fab) + agent               | Practice-leaning    |
| G8    | 09      | Midpoint week: *skip long input* **or** 10 min “setup pattern” tip | Practice            |
| G9    | 10      | Authorship / ghost work / platform dependency                      | Theory              |
| G10   | 11      | Ecology / data centres / when *not* to use AI                      | Theory              |

*technical suggestion:* Assign G8 a short practical tip so midpoint demos stay long enough; or leave G8 free and give that pair a slot only if someone drops.

Groups pick sources from [[references]], session notes, and research handouts — not only YouTube summaries.

## 3. Time budget (sessions 2–11)

| Block | Duration | Notes |
|---|---|---|
| Check-in | ~15–20 min | Listen only |
| Student input | ~15 min | One pair |
| Teacher critical / framing | ~20–30 min | Can shrink if input was strong |
| **Technical** | **≥45 min** | Install, vault, MCP, comparisons, studio |
| Buffer / break | remainder | Depends on total slot length (*todo:* confirm 90 vs 180 min) |

**Session 1:** no 45 min tech requirement; landscape + setup *proposal* only.  
**Sessions 12–13:** technical time is studio / presentations (still ≥45 min working or presenting).

**Flipped default:** long installs, dual-GPU reading, and multi-hour model downloads happen **at home**; class is for unblock + shared practice.

## 4. Crowding analysis (confirm)

**Confirm: the old 13-week map was crowded** once you add honest check-in (~15–20 min) + student input (15) + critical frame + ≥45 min tech.

Mitigations **implemented**:

1. Inserted **session 04 — local hardware** (was missing / buried in 03+10).  
2. **Merged** former studio + peer critique into **session 12** (freed one slot).  
3. Net **still 13 sessions**; midpoint = session **09**; ecology = **11**; final = **13**.  
4. Hardware DIY depth → homework + [[howto-local-llm-hardware]]; class = decision map + one small local run.  
5. Session 03 keeps cloud Hermes install; session 04 local; session 05 wiki/phone — no longer three themes in one afternoon.

Still tight if the official slot is **only 90 minutes** — then cut teacher framing first, never the check-in or the 45 min tech floor. *todo:* lock calendar length.
