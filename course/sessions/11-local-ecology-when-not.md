# Session 11 - Ecology / data centres, when *not* to use AI

Parent: [[../timeline]] ? Rhythm: [[../course-rhythm]]

**How to build** local boxes was session [[04-local-hardware-and-open-llms]]. This week asks **whether**, at what energy/water/siting cost, and when to refuse the agent.

## Goals

- Ground ecological claims (energy, water, siting) without hand-waving
- Compare cloud convenience vs local/EU/open stacks students can actually run
- Practice deciding **not** to use an agent

## Class rhythm

1. Check-in (listen only) - [[../course-rhythm#check-in-every-session]]
2. Student input (~15 min) - G10 ecology / when-not theme
3. Teacher framing
4. Technical >=45 min (comparisons + kill-switch rules)

## Teacher input

- **Data centres as material politics** - [[../../research/data-centers-energy-ecology-economy]] (~25-35 min). Optional prep: Be Smart, *The Real Cost of AI Will Shock You* (https://www.youtube.com/watch?v=YgoiujmwLKI). CapEx twin: [[../../research/ai-bubble-productivity-datacenter]]
- Prefer **IEA** + Luccioni over vendor blogs for numbers
- Local as political/aesthetic choice - point back to session 04 hardware map; here emphasise **utilisation, electricity, renting vs owning** ([HM Munich Our Br00d](https://mediapool.hm.edu/media/dachmarke/dm_lokal/hm_international/sprachen/coursesinenglish_1/courses_in_english_ss_26/muc_dai_5/CiE_Kursbeschreibung_Our_Br00d_Technical_Development_of_Agentic_AI_in_Artistic_Research_Geaendert.pdf))
- [SFPC handmade](https://sfpc.study/sessions/summer-26/handmade-datasets) scale + LLM Wiki small-base bet ([[../../research/karpathy-llm-wiki-and-openclaw]])
- Checklist: when AI is useful / unnecessary (*requirement* from brief)
