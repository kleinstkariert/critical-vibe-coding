## Teacher input — agent as interface (*practice* / studio framing)

Prompts for discussion and mini-lecture:

- Interface = harness design: what you can ask, what the agent can touch (session 5 tool list), what it must refuse, how it remembers (`SCHEMA.md`, `index.md`, `log.md` — [[../llm-wiki-standard-files]] · [[../what-is-harness]])
- Skills and schema as score / dramaturgy — the schema is the only place the “character” of the agent is written down
- Failure modes as aesthetic (hallucination, sycophancy, tool refusal). Primary case: OpenAI rolled back a GPT‑4o update on 2025‑04‑29 because it had become “overly flattering or agreeable” — the vendor’s own account: https://openai.com/index/sycophancy-in-gpt-4o/ (*verified fact*; read as a vendor statement, not neutral analysis)
- Audience: is the agent for the artist only, or for visitors?
- Relation to IC history of interfaces, embodiment, and systems

## Practical / workshop

- Each student: one-page “interface score” for their agent (roles, tools, memory, taboos)
- Pair critique: does the score match what the setup actually does? (Check against the real `SCHEMA.md` and the real tool list, not the intention.)

## Homework

- Revise schema to match the interface score (taboos → human-only paths and “must ask first” tools in `SCHEMA.md`)
- Bring a rough idea for midpoint proposal (session 7)
