# Session 11 — Studio — build, break, document the setup

Parent: [[../timeline]]

## Goals

- Protected work time on personal agent + project interface
- Document architecture as you go (final presentation needs it)
- Teacher floating support / debugging

## Check-in

Blockers board: sync, model auth, MCP, concept stuck.

## Studio

Suggested stations:

1. Stability — vault sync, secrets out of notes, backup; run a **lint** pass and clear the high-severity items ([[../what-is-lint]])
2. Skills — one new skill that matters for the art use (Hermes skill or a schema section; MCP server if the tool is not a folder — [Hermes MCP docs](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp))
3. Interface — visitor-facing vs artist-only path (Discord channel rules are one concrete place this is decided: DMs, mention-only channels, free-response channels — [Hermes Discord setup](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/discord))
4. Documentation — diagram + short critical note draft; *technical suggestion:* `SCHEMA.md` + `index.md` already describe most of the architecture — reuse them instead of writing a second document ([[../llm-wiki-standard-files]])

## Peer help

Pair programming / pair prompting encouraged; log who helped in the wiki (*technical suggestion:* a `## [date] update | peer-help …` line in `log.md` keeps it in the append-only history).

## Homework

- Freeze a “demo script” for session 11 critique (5–7 minutes)
- Bring one unresolved critical question
