# Session 12 — Peer critique — setup and project together

Parent: [[../timeline]]

## Goals

- Critique **setup and project as one object**
- Tighten demos for final
- Surface shared problems (sync, authorship, cost)

## Check-in

What do you want feedback on today — tech, concept, or both?

## Critique format (suggested)

For each student:

1. Demo script (timed)
2. Peers: Keep / Change / Question
3. Teacher: one technical, one critical note

*technical suggestion:* let peers read the student’s latest lint report and `SCHEMA.md` *before* the demo — critiquing the knowledge base is part of critiquing the work ([[../what-is-lint]]).

Assessment echo: [Birkbeck](https://www.bbk.ac.uk/courses/modules/sc04/SC04023S7)-style practice + reflection pairing ([[../timeline]]) — reflection can stay short.

## Homework

- Finalise presentation for session 12
- Optional: export or publish a non-secret slice of the wiki / diagram — check `raw/` first: ingested third-party articles and transcripts are not yours to republish; publish the agent-written wiki pages, the schema and the diagram instead ([[../llm-wiki-standard-files]])
