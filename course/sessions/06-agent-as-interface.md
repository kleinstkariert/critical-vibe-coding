# Session 06. The agent as interface, as material, as canvas

Parent: [[../timeline]] · Rhythm: [[../course-rhythm]]

**Slot:** 10:00 to 12:00.

## Goals

- Name the Interface Cultures angle: the **agent setup** is material, not only the outputs it produces
- Three readings: the agent **as interface** (what you can ask, what it can touch), **as material** (schema, tools, memory as stuff to shape), **as canvas** (the setup as the surface where the work appears)
- Look at art and research examples where conversation, tools or agent behaviour *are* the work
- Students sketch how their setup enters their semester project

## Teacher input: agent as interface, material, canvas (*practice* / studio framing)

Prompts for discussion and mini-lecture:

- **Interface** = harness design: what you can ask, what the agent can touch (Session 05 tool list), what it must refuse, how it remembers (`SCHEMA.md`, `index.md`, `log.md`: [[../llm-wiki-standard-files]] · [[../what-is-harness]])
- **Material:** skills and schema as score and dramaturgy. The schema is the only place where the "character" of the agent is written down.
- **Canvas:** the setup itself as the place where the work happens or is shown (a vault as a publication, an agent as a performer, a log as a score).
- Failure modes as aesthetic (hallucination, sycophancy, tool refusal). Primary case: OpenAI rolled back a GPT-4o update on 2025-04-29 because it had become "overly flattering or agreeable", the vendor's own account: https://openai.com/index/sycophancy-in-gpt-4o/ (*verified fact*; read as a vendor statement, not neutral analysis)
- Audience: is the agent for the artist only, or for visitors?
- Relation to IC history of interfaces, embodiment and systems
- Flattening as the counterforce: [[../lectures/01-welcome-landscape-deep-dives/flattening-and-the-norm]]

## Practical / workshop

- Each student: one-page **interface score** for their agent (roles, tools, memory, taboos, kill switch)
- Pair critique: does the score match what the setup actually does? (Check against the real `SCHEMA.md` and the real tool list, not the intention.)

## Homework

- Revise the schema to match the interface score (taboos → human-only paths and "must ask first" tools in `SCHEMA.md`)
- Bring one small task from your own stack (code, node, GUI, CAD/3D) to Session 07
