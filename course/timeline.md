## Abstract (course goal)

Students learn to build and run their own powerful LLM-agent setups while unpacking the political and economic forces that made these tools feel inevitable. The seminar is a technical workshop and a shared space to name fears, hopes, and authorship questions — with the agent itself treated as an interface for media-art practice, not only as a means to an output.

## Twin tracks (every session)

| Track | What it serves |
|---|---|
| **Technical** | Working personal agent (Hermes + Obsidian / LLM Wiki by default); phone sync; optional Discord channel to the agent |
| **Critical / “group therapy”** | Check-in, political-economic framing, authorship and labour, ecological and regulatory claims |
| **Agent as interface** | Setup, skills, knowledge base, and tool wiring as artistic/technical material — not only the generated artefact |

Each class starts with a short welcome and check-in (*requirement* from brief).

| Milestone | When | Deliverable |
|---|---|---|
| **Midpoint** | Session 8 | Live demo of personal agent setup (wiki/skills/tools) + short written proposal for how the *setup* enters an art/semester project |
| **Final** | Session 13 | Presentation: (1) agent architecture (diagram or walkthrough), (2) one artistic or research use, (3) short critical reflection (platform, ecology, authorship, or labour). Not a polished exhibition by default |
