# Minimum path

This page states the work that is required.
The other tools in this repository are choices.
No purchase is required.
Alternatives are allowed.

You can complete the course with one agent and one folder.
You do not need Hermes, Obsidian, phone sync, a local model, MCP, Discord, or a bridge to another application.

## Required work

Do these steps.
At best, this work is part of your own art project.

1. Create a plain Markdown workspace. A folder of `.md` files is enough.
2. Run one agent. The agent can be in the cloud or on your own computer.
3. Give that agent access to one folder that you control.
4. Perform one useful task with the agent.
5. Record the task, the model, the tools, and the outcome.
6. Review the result.
7. Write one critical reflection.
8. Present the architecture and one use.

## Required: input presentations

You also give one input presentation with your group.
The topics and the sessions are in the [course rhythm](syllabus/course-rhythm.md).
One group presents in sessions 2, 3, 5, 6, and 7.

The presentations in sessions 4 and 8 use the steps above.
Session 4 shows the work as it stands.
Session 8 presents the architecture, one use, and the critical reflection.

## How to read the other pages

| Label | What it means |
|---|---|
| *optional extension* | A further tool or habit. You can skip it and still complete the course. |
| *advanced path* | A harder setup, such as a local model, a coding harness, or MCP. |
| *demonstration* | One example the class may watch. You do not have to copy that example. |
| *research topic* | Reading and discussion. It is not an install task. |
| *not required for assessment* | It does not decide whether you pass. |

The seminars still discuss political economy, labour, ecology, bias and feminism, authorship, privacy, and critique.
Use those themes in the input presentation and in the critical reflection.
They are not a list of software to install.
