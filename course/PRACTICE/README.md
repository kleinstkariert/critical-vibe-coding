# Practice

This folder holds the technical notes.
They support the seminar. They do not define one correct setup.
No purchase is required. Alternatives are allowed.
Any one agent plus one folder meets the [minimum path](../PROJECT-WORK/01_minimum-path.md).
Hermes is one *reference implementation* and a class *demonstration*. It is *not required for assessment*. Compare the tools in the [tool comparison](../../research/software&DataManagement/vibe-coding-tools-and-agent-environments.md).
