# Presentation style — Schaufler / Quadrature

Rules for CVC lecture decks and related talks. Full agent skill: `.cursor/skills/schaufler-presentation-style/SKILL.md` (also in personal Cursor skills).

**Reference archive:** `Nextcloud/_QUADRATURE/07_Talks/2026_SchauflerResidencyTalks`  
Especially: *Kunst & Kapitalismus @ Mass of Money* (notes PDF), Fantasie tech-flow diagram, installation photos (CREDO, etc.).

## In short

| Do | Don’t |
|---|---|
| One strong image or quote per slide | Bullet walls / dashboards |
| Argument in speaker notes | Reading paragraphs off the slide |
| Artworks, infra photos, sparse diagrams | Neon “AI brain” stock |
| Label *claim* vs *verified fact* | Confident unsourced numbers |
| Contradiction as method (image vs market) | Pure tech demo cheerleading |
| Own installation photos for practice beats | Logo salad of every vendor |

## When drafting lecture `.md` files

Each block should have: **Say** · **Image suggestions** (table) · **Q&A prompt**.  
Example: [[lectures/01-welcome-landscape-lecture]].
