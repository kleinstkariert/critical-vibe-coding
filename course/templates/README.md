# Templates

These are blank forms. Copy one into your own knowledge store, fill it in, and delete the instruction lines. The guide page for each form says what is required and why.

The templates follow the order of the course. They do not require one agent architecture. A student who works with Hermes, Cursor, a local script, a visual tool, or no AI can use them.

| Order | Template | Use it for | Guide page |
|---|---|---|---|
| 1 | [Manifesto](manifesto.md) | The personal manifesto. Start in Session 01, hand in at the end | [Minimum path](../PROJECT-WORK/01_minimum-path.md#required-personal-manifesto) |
| 2 | [Group input presentation](group-input-presentation.md) | Your group input in Session 02, 03, 05, 06 or 07 | [Minimum path](../PROJECT-WORK/01_minimum-path.md#required-input-presentations) and [course rhythm](../SESSIONS/overview/course-rhythm.md) |
| 3 | [Project proposal](project-proposal.md) | The semester plan for Session 04 | [Project path](../PROJECT-WORK/02_project-path.md#proposal) |
| 4 | [Midpoint check](midpoint-check.md) | The system as it stands, Session 04 | [Project path](../PROJECT-WORK/02_project-path.md#midpoint) |
| 5 | [Provenance note and process log](provenance-note-and-log.md) | The record of task, model, tools, decisions and outcome | [Provenance](../PROJECT-WORK/03_provenance.md) |
| 6 | [Verification plan](verification-plan.md) | How you check the result | [Verification](../PROJECT-WORK/04_verification.md) |
| 7 | [Interface score](interface-score.md) | One page on how the agent meets you. Session 06, optional | [Interface score](../PROJECT-WORK/05_interface-score.md) |
| 8 | [Final presentation](final-presentation.md) | Session 08 | [Project path](../PROJECT-WORK/02_project-path.md#final) |
| 9 | [Critical reflection](critical-reflection.md) | The short text on what the system did to the work | [Reflection](../PROJECT-WORK/06_reflection.md) |

Do not write secrets, keys, or private vault content into any of these files. You may share them with the class.
