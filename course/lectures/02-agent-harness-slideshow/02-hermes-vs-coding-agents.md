# Three harness families

| Family | Job |
|---|---|
| Hermes | Open multi-channel agent you own |
| Claude Cowork-style | Always-on knowledge assistant |
| Claude Code / Cursor | Deep repo coding loop |

They are not the same product. Pick by job.

Note: [[hermes-vs-coding-agents]]

---

# Coding depth

**Claude Code / Cursor:** strongest IDE and terminal coding loops.

**Hermes:** can code; not the deepest repo agent. Can hand off to Claude Code / Codex / OpenCode.

**Cowork:** knowledge work, not multi-file software shipping.

Desktop GUI for Hermes: [[howto-hermes-setup]] · hermes-agent.nousresearch.com/desktop

---

# MCP · creative tools

vvvv · TouchDesigner · Unity · other apps via MCP servers.

Hermes: MCP client (and can serve MCP). Built for many softwares, not only an IDE.

Cursor / Claude Code: strong MCP inside the coding loop.

Course bet: agents across tools, not only in the editor. See [[what-is-mcp]]

---

# Open · local · data

| | Hermes | Cursor / Claude Code | Cowork |
|---|---|---|---|
| Open source | MIT | No | No |
| Local open weights | Yes | No (Claude-only / cloud-first) | No |
| You pick the endpoint | Yes | Vendor stack | Anthropic cloud |

Local model ≠ safe agent. Approvals and sandboxes still matter.

---

# Always-on · messaging

Hermes: Telegram, Discord, Matrix, Signal, … · optional Cloud 24/7.

Cowork: scheduled / cloud sessions in Claude’s apps.

Coding agents: weak as a phone-first assistant.

---

# Course posture

**Hermes = default commons harness** (vault, local, MCP, phone).

**Cursor / Claude Code = coding intensifier** when the repo is the work.

Modes on coding tasks: coding / production / hybrid · [[howto-hermes-efficient-coding]] · [[agents-md-template]]

Do not claim Hermes beats Cursor at IDE coding. Claim control, openness, and multi-tool reach.
