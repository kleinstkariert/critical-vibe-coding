# Research index

These notes support the course. They are not sessions, and they are not required installs.

A path in a research note that points at clips means the teacher vault, not a folder in this repository.

## Layout

| Place | What it holds |
|---|---|
| This folder | Humanistic, social and conceptual research: economy, labour, ecology, thinking |
| [software&DataManagement](software&DataManagement/README.md) | Software, tools, hardware and data-management research |
| [externalReferences](externalReferences/README.md) | Condensed notes on work by other groups |

A note is placed by its main purpose. A note about a tool is in `software&DataManagement/`. A note about what a technology does to people, work or the planet is in this folder.
